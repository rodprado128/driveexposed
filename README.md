# Drive Exposed

Auditoria de permissões do Google Drive. Veja quem tem acesso aos seus arquivos e revogue com um clique.

🔗 **Acesse**: [Adicione aqui a URL do GitHub Pages após o deploy]

## Sobre

Projeto pessoal que ajuda você a:

- Listar todos os arquivos e pastas compartilhados do seu Google Drive
- Identificar acessos externos ao seu domínio
- Detectar arquivos com acesso público por link
- Revogar permissões individualmente ou em lote
- Exportar relatório para Google Sheets

## Como funciona

O Drive Exposed é composto por duas partes:

1. **Landing page** (este repositório) — interface estática hospedada no GitHub Pages
2. **App** — Google Apps Script Web App rodando na conta do próprio usuário

Nenhum dado sai da sua conta Google. Todo o processamento acontece dentro do seu próprio Apps Script.

## Tecnologia

- HTML/CSS puro, sem build step
- Material Symbols + Google Sans
- Google Apps Script (backend)
- Google Drive API v3
